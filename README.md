# dr-albar.com

الموقع الرسمي للدكتور محمد البار — HTML/CSS/JS ثابت، بلا npm وبلا خطوة بناء.

## الهيكل

| المسار | المحتوى |
|---|---|
| `/` | الصفحة الرئيسية |
| `/patients/` | محتوى تعليمي للمرضى (بلا استشارات، بلا بيانات مرضى) |
| `/orl101/` | دورة الأساسيات — صفحة تعريف + تسجيل اهتمام |
| `/fess101/` | دورة جراحة الجيوب بالمنظار — تعريف + خريطة الوحدات + تسجيل اهتمام |
| `/orl-daily/` | ملخص الأبحاث اليومي والأرشيف؛ قراءة مباشرة من `malbarr/orl-daily/data/` |
| `/verify/` | التحقق من شهادة برقمها (يحتاج `/api/verify`) |
| `/about/` | نبذة وتواصل |

## النشر

مسار النشر المتحقق منه في 9 أكتوبر 2026: GitHub Pages من الفرع `main` وجذر المستودع، مع النطاق `dr-albar.com`. لا يحتاج هذا الربط إلى تغيير DNS أو نقل الاستضافة. تبقى الملفات متوافقة مع الاستضافة الثابتة بلا npm أو خطوة بناء.

## نقاط مؤجَّلة (backend)

- `POST /api/interest` — حفظ تسجيلات الاهتمام.
- `GET /api/verify?id=` — التحقق من شهادة.

كلاهما يُنفَّذ لاحقاً بـ Cloudflare Pages Functions + D1. حتى ذلك الحين تظهر رسالة واضحة للمستخدم بأن الخدمة غير مفعّلة.

## تحديث ملخص الأبحاث — تلقائي، للقراءة فقط

- `assets/orl-daily.js` يقرأ فهرس `https://raw.githubusercontent.com/malbarr/orl-daily/main/data/index.json` وملف التاريخ المختار، ويعرض النص داخل تصميم الموقع. القراءة البديلة عبر GitHub Pages للمستودع نفسه عند تعذر المصدر الأول.
- النشر المعتاد في مستودع ORL Daily (ملف الإصدار + إدراجه في `data/index.json`) كافٍ؛ لا تعديل للموقع أو نسخ للبيانات أو اشتراك أو مفتاح API لكل إصدار.
- جميع تواريخ المصدر متاحة دون حد أقصى أو حذف؛ الأرشيف مجمّع حسب السنة والشهر. يجري تحميل الإصدار المطلوب فقط، وليس كامل الأرشيف عند فتح الجوال.
- صفحة القسم تدعم العربية والإنجليزية، البحث داخل الإصدار، PubMed وDOI، والتحليل العلمي، وروابط داخلية ثابتة مثل `/orl-daily/?date=2026-10-09`.
- الرئيسية تعرض ثلاث معاينات حقيقية من أحدث إصدار، تقود إلى الملخصات داخل الموقع.
- يتحقق الموقع من المصدر عند الفتح، ثم كل خمس دقائق حين يكون ظاهرًا، وعند العودة إلى التبويب بعد دقيقة. يُستخدم مفتاح تخزين مؤقت متجدد كل دقيقة و`no-store`؛ وقد يبقى تأخر قصير من شبكة توزيع المصدر أو مسار القراءة البديل.
- لا تُنشأ نسخ بيانات في مستودع الموقع. `orl-daily/issues.json` ملف قديم غير مستخدم؛ تركناه دون حذف. لم يعد يحتوي على قائمة يحتاج أحد لتحديثها يدويًا.
- أخطاء الشبكة تظهر كأخطاء تحميل، لا كرسالة توحي أن الأرشيف غير موجود. النسخة المعروضة عند فشل إعادة التحديث تُوسم بوضوح.
- نص المصدر يُدرج عبر `textContent`، وتُتحقق روابط PubMed/DOI؛ لا HTML بعيد ولا أسرار ولا إرسال لبيانات المرضى. لم يُغيّر هذا الربط صفحات المرضى أو معلومات التواصل.

### اختبار الربط

يشغّل `tests/test_orl_daily.py` اختبارات متصفح على خادم محلي، مع نسخة اختبار مقروءة من المستودع العلمي. يختبر جميع تواريخ الأرشيف، العربية/الإنجليزية، الروابط، الجوال، الإصدارات المستقبلية بمحاكاة محلية فقط، ومسار الفشل. لا تُنشر بيانات الاختبار.
